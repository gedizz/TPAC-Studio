# Original examples

Run `python examples/build_demo.py --output local/demo` after installation. It generates original procedural assets, a plan, a TPAC and a saved workspace. Use a fresh output directory for each run; the example deliberately does not overwrite outputs. These are synthetic tool fixtures, not engine-certified production assets.

`extension/` is a separately installable example provider; see [the extension guide](../docs/extensions.md). All example code/data is original MIT work credited to X7 Dragon. No game installation, proprietary template or download is needed to run the demo.
